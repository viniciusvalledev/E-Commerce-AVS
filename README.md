## About the Project

**E-Commerce AVS** is an online store application built to simulate a complete digital marketplace environment. The system allows users to browse products, manage their cart, and interact with an intuitive interface designed for optimal user experience across devices.

---

## Technologies Used

* **Frontend:** HTML5, CSS3, JavaScript
* **Styling & Assets:** Custom UI components and responsive layouts

---

## Main Features

* **Product Catalog:** Browse through a variety of available items with detailed views.
* **Shopping Cart:** Add, remove, and manage items dynamically before checkout.
* **Responsive Layout:** Fully adaptable design for desktops, tablets, and mobile devices.
* **Clean Interface:** Modern and minimalist user experience focused on conversion and usability.
